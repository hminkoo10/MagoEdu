문의 보내기

메뉴의 문의하기에서 새 문의를 선택합니다. 제목과 내용을 쓰고 보내기를 누릅니다. 문의는 본인과 운영자만 볼 수 있습니다.

사진 붙이기

사진 붙이기로 PNG, JPG, WEBP 사진을 고릅니다. 글 하나에 3장, 한 장 5MB까지 붙일 수 있습니다. 잘못 고른 사진은 빼기로 뺍니다. 끝난 문의의 사진은 30일 뒤 삭제합니다.

답 확인

새 답글이 오면 메뉴에 숫자가 표시됩니다. 문의를 열어 답을 확인하고 아래 답글 칸에서 대화를 이어갑니다. 사진은 누르면 크게 표시됩니다. 끝난 문의에 답글을 보내면 다시 열립니다.

운영자 안내

문의에서 전체 또는 상태별로 확인합니다. 답글을 보내면 ‘답변함’으로 표시됩니다. 처리가 끝나면 끝내기를 누릅니다. 필요하면 다시 열기를 누릅니다.

PC 앱에서는 새 문의와 사용자 답글 알림을 받습니다. 알림을 누르면 해당 문의가 열립니다.

서버 설정의 ‘문의 알림’에 디스코드 웹훅 주소를 입력하고 저장을 누릅니다. 시험 보내기로 확인하며, 지우기로 끕니다. 새 문의의 번호·역할·학원·제목만 전송합니다. 본문과 사진은 보내지 않습니다.
