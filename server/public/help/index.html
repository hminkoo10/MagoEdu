마고에듀 소개

학원에서 사용하는 프로그램을 한곳에서 관리합니다. 통합 클라우드에서 프로그램을 설치하고 실행하며, 자료를 다른 컴퓨터와 동기화합니다.

PC의 마고에듀 통합 클라우드
로그인 → 설치 → 열기

↓

오답노트책에서 문제를 골라 학생 시험지를 만듭니다.
마고 타종정한 시각에 수업 종을 울립니다.
마고 과목내비학생의 학교와 진로에 맞춰 과목을 설계합니다.

같은 아이디로 로그인하면 다른 컴퓨터에서도 같은 자료를 이어서 사용할 수 있습니다. 이를 동기화(다른 기기와 내용을 맞추는 기능)라고 합니다.

학생은 프로그램을 설치하지 않습니다.인터넷 브라우저에서 mago.milky.kr을 열어 오답노트와 과목내비를 사용합니다.

사용자별 안내

원장용 안내가입, 계정·학생 명단·학원 AI를 준비합니다. 선생님용 안내받은 계정으로 로그인하고 수업을 준비합니다. 학생용 안내가입 코드 또는 임시 비밀번호로 시작합니다.

프로그램별 사용법

통합 클라우드설치·로그인, 프로그램·계정 관리 오답노트책 등록·분석, 번호 선택, 시험지 만들기 마고 타종시간표와 종소리 관리 마고 과목내비학생별 학교·진로·과목 설계

문제 해결

로그인이 되지 않거나 종이 두 번 울리면 자주 묻는 질문에서 상황을 확인합니다.

해결되지 않으면 왼쪽 메뉴의 문의하기에서 운영자에게 문의합니다. 사용법은 문의하기 안내에 있습니다.

프로그램의 도움말에서 현재 화면의 설명서를 엽니다. 통합 클라우드에서는 왼쪽 설정 위에 있습니다. 로그인 전 화면에서는 사용 설명서를 선택합니다.
