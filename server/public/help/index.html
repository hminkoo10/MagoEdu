마고에듀는 무엇인가요?

학원에서 쓰는 프로그램을 한곳에 모았어요. 통합 클라우드는 프로그램을 설치하고 켜는 출입구예요. 자료를 다른 컴퓨터와 똑같이 맞추는 일도 해요.

PC의 마고에듀 통합 클라우드
로그인 → 설치 → 열기

↓

오답노트책에서 틀린 문제를 골라 학생 시험지를 만들어요.
마고 타종정한 시각에 수업 시작·끝 종을 울려요.
마고 과목내비학생의 학교와 진로에 맞춰 고등학교 과목을 골라요.

같은 아이디로 로그인하면 다른 컴퓨터에서도 같은 자료를 이어서 써요. 이것을 동기화(다른 기기와 내용을 똑같이 맞추기)라고 해요.

학생은 설치하지 않아요.인터넷 브라우저에서 mago.milky.kr을 열어요. 내 오답노트와 과목내비를 웹에서 써요.

누구세요?

원장님이에요가입부터 선생님 계정, 학생 명단, 학원 AI까지 준비해요. 선생님이에요받은 계정으로 로그인하고 수업에 필요한 일을 시작해요. 학생이에요초대 코드나 임시 비밀번호로 시작해요. 프로그램 설치는 필요 없어요.

프로그램별 사용법

통합 클라우드설치·로그인, 프로그램 열기, 계정과 학원 관리 오답노트책 등록 → 분석 → 틀린 번호 고르기 → 시험지 만들기 마고 타종PC·휴대폰 시간표, 종소리, 제시간에 울리게 하기 마고 과목내비학생 → 학교 → 분야 → 대학 → 조건 → 결과 보기
