비밀번호를 잊은 경우

로그인 화면의 비밀번호를 잊었어요를 누르면 문의 대상을 안내합니다.

  • 학생: 담당 선생님에게 말씀드립니다. 선생님이 학생 명단 → 계정 관리에서 비밀번호 초기화를 합니다.
  • 선생님: 원장에게 요청합니다. 원장이 선생님 관리의 해당 계정 ⋯ → 비밀번호 초기화를 누릅니다.
  • 원장: 운영자에게 연락합니다.

새 임시 비밀번호를 받으면 로그인한 뒤 내 비밀번호로 바꿉니다. 로그인·새 비밀번호 정하기

프로그램이 실행되지 않습니다. ‘통합 클라우드에서 켜 주세요’가 나와요

오답노트·마고 타종의 실행 파일을 직접 켰을 때 나오는 안내입니다.

  1. PC의 통합 클라우드를 켭니다.

    원장이나 선생님 계정으로 로그인합니다.

  2. 프로그램 화면에서 엽니다.

    프로그램에서 원하는 카드의 설치를 누르고, 끝나면 열기를 누릅니다. 이미 설치했다면 바로 열기를 누릅니다.

웹의 PC에 설치·PC에서 실행은 그 PC의 통합 클라우드 앱을 여는 버튼입니다. 앱이 없다면 먼저 설치합니다. 카드 자체가 없으면 원장에게 프로그램 권한을 확인하도록 요청합니다.

통합 클라우드 설치 · 프로그램 설치·열기

‘동기화’란 무엇입니까?

동기화는 다른 컴퓨터와 자료를 맞추는 기능입니다. 같은 아이디로 로그인하면 자료를 이어서 사용합니다.

프로그램 카드에서 ‘동기화됨’을 확인한 뒤 다른 PC로 옮깁니다. 필요하면 모두 동기화를 누릅니다.

통합 클라우드 창을 닫아도 기본 설정에서는 트레이에서 계속 실행됩니다. 트레이의 종료로 완전히 끄면 동기화도 멈춥니다. 동기화·트레이 설명

인터넷 연결 끊김

이미 로그인하고 PC에 설치해 둔 프로그램은 받아 둔 자료로 계속 쓸 수 있습니다. 인터넷이 연결되면 통합 클라우드가 변경 내용을 다시 맞춥니다.

  • 오답노트: 받아 둔 책의 기본 분석과 노트 작업을 할 수 있습니다. 아직 받지 않은 공유 책과 인터넷을 쓰는 정밀 인식 기능은 연결이 필요합니다.
  • 마고 타종: 이 기기에 받아 둔 시간표와 종소리로 계속 울립니다. 다른 기기에서 바꾼 시간표는 다시 연결돼야 받습니다.
  • 웹·로그인·설치: 학생 웹, 첫 로그인, 새 프로그램 설치, 서버에 있는 자료를 새로 받는 일은 인터넷 연결을 확인합니다.

연결이 돌아오면 통합 클라우드의 동기화 상태를 확인합니다. 오류가 계속되면 화면의 안내를 원장이나 운영자에게 알립니다.

두 컴퓨터에서 함께 사용

네. 각 PC에 통합 클라우드를 설치하고 같은 아이디로 로그인하면 같은 데이터를 사용합니다. 다른 선생님은 각자의 계정을 쓰되, 같은 학원의 공유 책장과 학생 노트를 함께 이용합니다.

여러 사람이 같은 내용을 동시에 고치면 서로의 변경이 섞일 수 있습니다. 같은 학생을 함께 상담할 때는 누가 어느 부분을 고칠지 맞춰 두면 좋습니다.

타종은 소리를 낼 기기를 정합니다.시간표만 볼 PC·휴대폰에서는 설정 → 이 기기에서 종 울리기를 끕니다. 같은 아이디의 다른 기기 설정까지 꺼지는 것은 아닙니다.

책장·학생 노트 함께 쓰기 · 타종 기기 설정

종이 두 번 울림
  1. 예전에 따로 설치한 타종을 확인합니다.

    예전 타종과 통합 클라우드에서 연 새 타종이 함께 켜져 있으면 둘 다 울립니다. 예전 프로그램을 끕니다.

  2. 다른 PC와 휴대폰도 확인합니다.

    같은 아이디의 여러 기기에서 종 울리기가 켜져 있으면 각각 울립니다. 소리를 내지 않을 기기는 설정 → 이 기기에서 종 울리기를 끕니다.

  3. 다음 종을 확인합니다.

    홈에서 세트와 다음 시각을 확인합니다. 시간표에 같은 시간의 일정이 겹쳐 있는지도 살펴봅니다.

마고 타종을 완전히 끄는 메뉴는 트레이의 프로그램 끄기입니다. 통합 클라우드의 종료만 눌러서는 이미 켜진 타종이 계속 돌아갈 수 있습니다. 타종 시작·기기 확인

휴대폰에서 종이 울리지 않음
  1. 이 기기에서 울리도록 켜져 있는지 봅니다.

    마고 타종 설정 → 이 기기에서 종 울리기를 켭니다. 시간표·종소리를 받아 두었는지와 휴대폰 음량도 확인합니다.

  2. 알람 권한을 허용합니다.

    설정의 ‘정확히 울리게 하기’에서 ‘알람 및 리마인더’ → 허용하기를 누릅니다. 휴대폰 설정에서 허용한 뒤 앱으로 돌아옵니다.

  3. 배터리 최적화에서 제외합니다.

    같은 화면의 ‘배터리 사용량 최적화 제외’ → 제외하기를 누릅니다. 설정 뒤 ‘허용됨’·‘제외됨’으로 보이는지 확인합니다.

  4. 오늘 종이 멈춰 있는지 봅니다.

    홈에서 잠시 멈춤·오늘 하루 끄기·건너뛰기 상태와 다음 종을 확인합니다.

그림으로 보는 휴대폰 설정

오답노트 분석이 오래 걸림

스캔한 PDF나 사진은 글자를 읽는 과정이 더 필요합니다. 쪽 수가 많으면 시간이 걸릴 수 있습니다.

  1. 진행 상황을 확인합니다.

    분석 중인 쪽과 진행 막대가 움직이는지 봅니다. 다른 일 하면서 기다리기를 누르면 분석은 계속되고 다른 책이나 노트를 볼 수 있습니다. 앱은 종료하지 않습니다.

  2. 필요한 쪽만 분석합니다.

    멈추려면 멈추기를 누릅니다. 다시 분석할 때 ‘쪽 범위’에 5-30처럼 필요한 PDF 쪽만 넣으면 읽을 양을 줄일 수 있습니다.

  3. 애매한 쪽만 다시 확인합니다.

    인식 결과의 ‘확인이 필요한 쪽’에서 검토 또는 꼼꼼히 다시 찾기를 사용합니다. 정밀 인식이 준비돼 있으면 정밀 인식를 골라도 됩니다.

문제없음은 실제 쪽을 보고 결과가 맞을 때 누릅니다. 책 분석·인식 결과 확인

한글(HWPX) 내보내기
  1. 학생의 오답노트에서 문제를 고릅니다.

    틀린 번호를 고르고 미리보기로 확인합니다.

  2. 한글 형식을 선택합니다.

    ‘시험지로 내보내기’의 파일에서 한글(HWPX)을 고릅니다. 문제지, 해설지 또는 문제 + 해설을 누릅니다.

  3. 저장하고 한글 프로그램에서 확인합니다.

    저장할 곳을 묻는 창이 나오면 저장합니다. 기다리는 동안 다른 일 하면서 기다리기를 눌렀다면, 다 됐다는 알림의 저장하기를 누릅니다. 만든 파일을 열어 수식·줄바꿈·문항이 맞는지 확인합니다.

글자가 들어 있는 PDF는 글자를 읽어 옮깁니다. 스캔 PDF·사진은 처리 시간이 더 걸리고, 옮기지 못한 부분은 그림으로 남을 수 있습니다. 시험지 내보내기 자세히

학생이 PC 프로그램에 로그인이 안 됩니다

학생 계정은 웹(브라우저)에서만 쓸 수 있습니다.PC 통합 클라우드 앱·오답노트·과목내비 PC판에 로그인할 수 없는 것은 정상입니다.

컴퓨터나 휴대폰의 브라우저에서 mago.milky.kr을 열어 학생 계정으로 로그인합니다. 왼쪽의 내 오답노트, 마고 과목내비, 내 계정을 이용합니다.

과목내비는 magonavi.milky.kr에서 마고에듀 통합 클라우드 계정으로 로그인을 눌러도 됩니다. 학생 첫 사용 안내

설치할 때 ‘Windows의 PC 보호’ 창이 떠요

mago.milky.kr에서 받은 통합 클라우드 설치 파일인지 확인합니다. 그 파일이라면 다음 순서로 설치합니다.

  1. 추가 정보를 펼칩니다.

    ‘Windows의 PC 보호’ 창의 추가 정보를 누릅니다.

  2. 설치 파일을 실행합니다.

    실행을 누르고, 이어지는 설치 화면에서는 다음을 눌러 진행합니다.

실행 버튼이 없거나 다른 안내로 막히면 그 화면의 문구를 원장이나 운영자에게 알립니다. PC 설치 순서

지운 학생 복구
  1. 삭제한 학생 목록을 엽니다.

    원장이나 선생님 계정으로 통합 클라우드 학생 명단 → 삭제한 학생을 엽니다.

  2. 학생을 확인하고 되살립니다.

    학생 이름을 확인한 뒤 되살리기를 누릅니다. 같은 학원 사람은 보관 기간 안에 되살릴 수 있습니다.

화면에 표시된 보관 기간을 확인합니다.그 기간이 지나면 학생의 오답노트 등 자료도 함께 완전히 지워집니다. 완전히 지워진 학생은 이 버튼으로 되살릴 수 없습니다.

로그인 계정만 지운 경우에는 명단과 자료가 남아 있습니다. 명단의 계정 만들기로 로그인 계정을 다시 준비합니다. 학생 명단·계정 관리

문의처
  • 학생: 담당 선생님에게 먼저 물어봅니다.
  • 선생님: 계정·프로그램 권한·학원 정밀 인식은 원장에게 물어봅니다.
  • 원장: 가입 코드나 해결되지 않는 오류는 운영자에게 연락합니다.

프로그램 이름, PC인지 휴대폰인지, 누른 버튼, 화면에 나온 안내 문구를 함께 알리면 확인하기 쉽습니다. 비밀번호나 정밀 인식 연결용 비밀키는 보내지 마세요.

프로그램의 도움말로 해당 설명서를 다시 열 수도 있습니다. 프로그램별 설명서 찾기
